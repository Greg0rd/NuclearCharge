Только стабильные API: `@minecraft/server 2.0.0`, `@minecraft/server-ui 2.0.0`.

## ⚠️ Если старая версия не заменяется (телефон/Xbox)

Bedrock кэширует паки по UUID: при импорте новой версии может остаться старая.
Правильное обновление:
1. Удалите паки **Nuclear Charge [BP]/[RP]** из мира (настройки мира → Пакеты → удалить).
2. Настройки → Глобальные ресурсы / Хранилище → удалите оба пака из памяти устройства.
3. Импортируйте новый `NuclearCharge.mcaddon`.
4. Проверьте версию в списке паков: **1.6.0**.

## Установка

1. Откройте **NuclearCharge.mcaddon** — паки импортируются автоматически.
2. В настройках мира включите **Nuclear Charge [BP]** и **[RP]**.
3. При первом входе подтвердите разрешение на **скрипты**.

## Крафт

- **Ядерный заряд**: железо ×7 рамкой, блоки красного камня ×2 по бокам, ТНТ в центре.
- **Пульт подрыва**: медь / красная пыль / железо (столбик).
- **Пусковая станция**: железо ×5 низом и углами, блоки красного камня ×2, **медный блок** в центре.

## Пусковая станция (как пользоваться)

1. Поставьте станцию, встаньте рядом, ПКМ.
2. Возьмите **Ядерный заряд в руку** → ПКМ по станции → заряд в отсеке (индикатор краснеет).
3. ПКМ → «Задать координаты цели» → введите X, Y, Z (например `100`, `74`, `-138`).
   Высота Y — в границах мира, дальность 24…4096 блоков.
4. **Цель-метка** в креативе — раздел **Строительство** (Construction) или крафт:
   красная пыль крестом + железо. Без клавиатуры: поставьте метку в точке удара →
   ПКМ по станции → «🎯 Выбрать ближайшую цель-метку» → «► ПУСК ◄».
   Либо введите координаты вручную («⌨ Координаты вручную»).
5. Ракета летит по дуге — смотрите на **огненно-дымовой след**!
5. В точке прибытия: боеголовка взрывается, включается сирена на 8 секунд → детонация.

Слом заряженной станции возвращает заряд. Достать заряд — через меню станции.

## Активация заряда (напрямую)

| Способ | Действие | Таймер |
|---|---|---|
| 🔥 Кремень и огниво | ПКМ по заряду | 20 сек |
| 🔴 Красный камень | сигнал в соседний блок (по фронту сигнала) | 10 сек |
| 📡 Пульт подрыва | ПКМ пультом до 512 блоков | 3 сек |

## Взрыв (R=100, «чаша»)

1. Глобальная сирена на отсчёте, мигание, отсчёт на экране.
2. Вспышка (ослепление → свечение), тряска, **глобальный** взрыв 7 с, молнии.
3. **Волна ~90 с**: чаша вырезается кольцами (≤300 колонок/4 тика), стена огня и дыма,
   отбрасывание игроков на фронте, магма на дне, **вода испаряется**.
4. Верификация: 3 контрольных прохода добивают незагруженные колонки → **круг всегда полный**.
5. **Ядерный гриб ~60 с** до ~170 блоков, послесвечение шляпки.
6. Огненный шторм (140 очагов) и **радиация 10 минут** (точки на экране + Гейгер).
