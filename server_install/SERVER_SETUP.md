# 🖥 Установка Nuclear Charge v1.7.0 на сервер Bedrock

## Что должно быть включено (чек-лист)

| Параметр | Значение | Зачем |
|---|---|---|
| **Версия сервера** | Bedrock **1.21.90+** (лучше последняя 1.26.x) | `min_engine_version` аддона |
| **Версия игроков** | те же 1.21.90+ | иначе сервер не пустит с паками |
| **Эксперименты** | ❌ **НЕ нужны** | аддон только на стабильных API (`@minecraft/server 2.0.0`, `server-ui 2.0.0`) |
| **Читы (cheats) в мире** | ❌ не обязательны | скриптовые команды (`tickingarea`, `playsound`, `summon item`) работают без читов; если ваш хостинг требует — включение не мешает |
| **Скрипты** | ✅ разрешены по умолчанию на BDS | behavior pack выполняется на стороне сервера |
| **Ticking areas** | до 10 одновременно; аддон занимает максимум 9 с именами `ncq_*` и чистит за собой | аддон удерживает чанки волны и таймера |
| **Ресурс-пак у игроков** | скачивается автоматически при входе — игроки принимают загрузку | текстуры, модель ракеты, звуки |

---

## Способ A — самый простой (любой сервер и Realms)

1. На **локальном устройстве** создайте/откройте мир, добавьте оба пака (как обычно), зайдите в мир один раз — всё проверьте.
2. Закройте мир — паки уже записаны внутрь папки мира.
3. Загрузите **папку мира целиком** на сервер (`worlds/<ваш мир>/`) или на Realm (мир → заменить).
4. Ресурс-пак игрокам предложится при входе.

⚠️ Минус: обновлять аддон = заново перезаливать мир.

---

## Способ B — вручную на BDS / хостинге (рекомендуется для обновлений)

### Шаг 1. Остановите сервер.

### Шаг 2. Скопируйте паки в корень сервера

Из `NuclearCharge.mcaddon` (это zip — переименуйте в `.zip` и распакуйте) возьмите две папки и положите:

```
bedrock-server/
├── behavior_packs/
│   └── NuclearCharge_BP/        ← вся папка как есть
└── resource_packs/
    └── NuclearCharge_RP/        ← вся папка как есть
```

(На некоторых панелях папки называются `development_behavior_packs` / `development_resource_packs` — кладите туда, это равнозначно.)

### Шаг 3. Привяжите паки к миру

В папке мира `worlds/<имя-мира>/` создайте или дополните два файла
(готовые файлы лежат рядом с этой инструкцией):

**`world_behavior_packs.json`**
```json
[
  { "pack_id": "adc8d1be-bf3f-4382-b7d4-2d21881b8485", "version": [1, 7, 0] }
]
```

**`world_resource_packs.json`**
```json
[
  { "pack_id": "b8eea885-5d1f-40fc-827e-2ce121046bb3", "version": [1, 7, 0] }
]
```

⚠️ Версия должна **точно совпадать** с `header.version` в манифесте пака.
Если в мире уже есть другие паки — добавьте наши записи в массив через запятую.

### Шаг 4. Запустите сервер и проверьте

- Зайдите игроком → примите загрузку ресурс-пака.
- Проверка: `/give @s nuclear:nuclear_charge` — если предмет выдаётся, BP работает.
- В креативе: блоки «Ядерный заряд», «Пусковая станция», «Цель-метка» в разделе «Строительство».

---

## Обновление аддона на сервере

UUID у версий одинаковые, поэтому:
1. Остановите сервер.
2. Удалите старые папки `NuclearCharge_BP` / `NuclearCharge_RP` из `behavior_packs` / `resource_packs`.
3. Скопируйте новые.
4. В `world_*.json` поменяйте версию на новую (`[1, 7, 0]` сейчас).
5. Запустите сервер. Игрокам придёт обновление ресурс-пака.

---

## Особенности работы на сервере

- 🌍 **Звук глобальный** — сирена и взрыв слышны всем игрокам сервера (в других измерениях тише).
- 💥 **Взрыв меняет ~36 млн блоков** — делайте бэкапы мира; на слабых VPS волна может растянуться дольше (это нормально, скорость адаптируется бюджетом `waveBudget`).
- 🎯 Цель-метки и координаты станции сохраняются в мире (dynamic properties) — переживают рестарт.
- 🚫 Не выдайте игрокам пульт и заряд, если не хотите ядерной войны — рецептов крафта они тоже достигнут.
- 🔧 Все настройки — `CONFIG` в `behavior_packs/NuclearCharge_BP/scripts/main.js` (после правки перезапустите сервер).

# 📡 Подключение Xbox к серверу по локальной сети

## Почему Xbox не видит сервер напрямую

Xbox ищет LAN-миры через **NetherNet** (WebRTC-транспорт Microsoft, UDP-порт 2225) и Xbox Live (UDP/TCP 3074). Ошибка `InitialConnection-145` = пакеты до ноутбука не доходят. Телефон видит сервер простым пингом UDP 19132 — поэтому он и видит, а бокс нет.

## Шаг 1. Быстрый тест (определяем виновника)

На ноутбуке временно **выключите брандмауэр Защитника** (Пуск → «Брандмауэр Защитника» → включение/отключение → «Отключить» для **частной сети**). Попробуйте зайти с Xbox.
- **Зашли** → виноват файрвол, делаем Шаг 2 и включаем файрвол обратно.
- **Не зашло** → идём к Шагу 3 (NAT) и Шагу 5 (BedrockConnect).

## Шаг 2. Правила брандмауэра Windows (cmd от администратора)

```
netsh advfirewall firewall add rule name="Minecraft BDS" dir=in action=allow protocol=UDP localport=19132
netsh advfirewall firewall add rule name="NetherNet" dir=in action=allow protocol=UDP localport=2225
netsh advfirewall firewall add rule name="Xbox Live" dir=in action=allow protocol=UDP localport=3074
netsh advfirewall firewall add rule name="Xbox Live TCP" dir=in action=allow protocol=TCP localport=3074
```

И проверьте профиль сети: **Настройки → Сеть → Wi-Fi → ваш адаптер → «Частная сеть»**
(в «Общедоступной» входящие блокируются даже с правилами).

## Шаг 3. NAT на Xbox и роутере

1. Xbox: **Настройки → Общие → Параметры сети → Проверить тип NAT**.
   - «Открытый»/«Умеренный» — ок. «Строгий» — вот причина.
2. Роутер (админка `192.168.1.1` / `192.168.0.1`): включите **UPnP** (раздел WAN/Advanced) → перезагрузите роутер → повторите тест NAT.
3. Если UPnP нет: проброс портов —
   - UDP 19132 → IP ноутбука
   - UDP/TCP 3074 → IP Xbox
4. Проверьте, что у Wi-Fi **отключена «изоляция клиентов»** (AP Isolation — обычно в гостевых сетях; из-за неё устройства Wi-Fi не видят друг друга).

## Шаг 4. Закрепите IP за ноутбуком

В админке роутера: **DHCP → привязка по MAC-адресу** → например `192.168.1.50`.
Иначе после перезагрузки роутера IP сменится, и Xbox будет стучаться «в пустоту».

## Шаг 5. BedrockConnect — надёжный обход (если 145 не уходит)

Xbox не умеет подключаться по IP — BedrockConnect обходит это через «избранные серверы»:

1. **Xbox → Настройки → Общие → Параметры сети → Дополнительные → Параметры DNS → Вручную:**
   - Основной: `104.238.130.180`
   - Вторичный: `8.8.8.8`
2. **Полностью закройте Minecraft** (кнопка Xbox → выйти из игры) и перезапустите консоль.
3. Minecraft → вкладка **«Серверы»** → зайдите на **The Hive** (или Galaxite/Lifeboat/Mineville/Enchanted).
4. Вместо сервера откроется **меню BedrockConnect** → «Connect Manually».
5. Введите IP ноутбука, порт `19132` → Connect. Кнопкой «Add to Server List» сохраните.
6. Согласитесь скачать **ресурс-пак** (без него блоки фиолетовые, звуков нет).

Побочный эффект: избранные серверы теперь всегда открывают меню BedrockConnect.
Вернуть как было: Параметры DNS → «Автоматически».

## Диагностика: симптом → причина → лечение

| Симптом | Причина | Лечение |
|---|---|---|
| `InitialConnection-145` | файрвол / строгий NAT | Шаги 1–4, иначе Шаг 5 |
| Мир виден, но «Не удалось подключиться» | версия клиента ≠ сервера | обновите BDS до 1.26.x |
| BedrockConnect не открывается | DNS не применился | перезапуск консоли, проверить DNS |
| BC открылся, но «Connection refused» | неверный IP или файрвол | `ipconfig`, Шаг 2 |
| Подключился, блоки фиолетовые | RP не принят | выйти, зайти, принять пак |
| Телефон видит, бокс нет | это нормально для Xbox | Шаг 5 |
